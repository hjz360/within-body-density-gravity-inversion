# 全变密度训练集 A 的结果（2026-11-25）

方案：`training_v2/allvar_protocol_zh.md`（提交 b3e2f59，训练前写定）。训练集核对：训练集与验证集中规则 0 为 0 个，规则 1—4 各 25%；留出 400 例未改动。验证损失最小轮次：种子 1—3 为第 67、78、62 轮。评价脚本 `a_pred.py`、`a_eval.py`；判读结果 `decision.json`。

## 判读（测试集 200 对，验证最佳权重）

| 规则 | 内容 | 结果 |
|---|---|---|
| 1 | A 相对 H 的体内起伏误差平均降低 ≥5%，至少两个种子区间不含 0 | 不成立。平均增加 1.4%（+0.9%、+5.3%、−1.9%） |
| 2 | 理论 12 例 Dice 三个种子都高 ≥0.02，或测试集密度 RMSE 平均降低 ≥5% | 不成立。Dice 差 −0.020、+0.003、+0.031；RMSE 平均增加 0.3% |
| 3 | A 的响应误差三个种子都低于 C，至少两个区间不含 0 | 成立。低 3.7%、2.5%、4.2%，三个区间都不含 0 |
| 4 | A 的虚假起伏至少两个种子高于 H 且区间不含 0 | 成立。种子 1、2 高 2.0%、5.1% |

结论：去掉均匀样本没有改善反演效果（导师的判断不成立）；H 相对 C 的响应优势来自体内变化本身，不是均匀样本比例造成的。按方案，论文仍以 H 为主，报告 A 的结果，删去"两个因素没有分开"的局限。
